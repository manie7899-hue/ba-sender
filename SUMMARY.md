# BA Sender — сводка

## Что это

Telegram-бот для автоматической отправки сообщений продавцам на OLX.BA. Использует Playwright (Chromium) и RedScript API для ссылок.

---

## Основные функции

- **Аккаунты** — добавление OLX-аккаунтов (email + пароль)
- **Сессии** — привязка аккаунта к списку ссылок и прокси
- **Сообщение** — текст первого сообщения продавцу
- **RedScript** — API для создания ссылок (второе сообщение)
- **Запуск** — отправка по всем сессиям с задержкой между сообщениями
- **Скриншот** — фото чата после каждой успешной отправки
- **Модерация** — заявки на доступ (ADMIN_CHAT_ID)

---

## Скорость (задержка между сообщениями)

| Режим | delay_min | delay_max | Пауза |
|-------|-----------|-----------|-------|
| Быстро | 1 | 2 | 1–2 сек |
| **Средне** ✓ | 3 | 5 | 3–5 сек |
| Медленно | 8 | 15 | 8–15 сек |

Сейчас по умолчанию: **3–5 сек** (средний режим).

---

## Развёртывание

### Render.com
- **Runtime:** Docker
- **Instance:** Standard (2 GB)
- **Env:** `BOT_TOKEN`, `ADMIN_CHAT_ID`
- Инструкция: `deploy/RENDER.md`

### Windows (локально)
```cmd
deploy\install.bat
notepad config.py
deploy\run.bat
```

### Linux VPS
```bash
./deploy/install.sh
nano config.py
./deploy/run.sh
```
