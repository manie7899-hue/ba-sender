# BA Sender — автоотправка сообщений на OLX.BA

Приложение для автоматической отправки сообщений продавцам на сайте OLX.BA. **Всё в одном приложении.**

## Возможности

- **Прокси** — один прокси или список (ротация), форматы: `host:port`, `user:pass@host:port`, `http://`, `socks5://`
- **Аккаунты** — хранение нескольких аккаунтов OLX.BA, автоматический вход перед отправкой
- **Мультизадачность** — несколько сообщений отправляются параллельно
- Настраиваемая задержка между сообщениями (антибан)
- Импорт ссылок и прокси из файлов
- Автосохранение настроек, аккаунтов и прокси
- Лог всех операций
- Сборка в один EXE-файл

## Установка и запуск

### Вариант 1: Запуск через Python

1. Установите Python 3.10 или новее
2. Откройте папку `BA send` в терминале
3. Выполните:

```bash
pip install -r requirements.txt
playwright install chromium   # обязательно! без этого приложение не запустится
python app.py
```

**Важно:** Команда `playwright install chromium` скачивает браузер (~170 МБ). Выполните её один раз после установки зависимостей.

### Вариант 2: Сборка EXE

1. Запустите `build_exe.bat`
2. После сборки EXE будет в папке `dist\BA_Sender.exe`
3. **Важно:** перед первым запуском EXE один раз выполните в командной строке:
   ```bash
   playwright install chromium
   ```
   (если Python установлен глобально)

## Использование

1. **Прокси** (опционально) — введите один прокси или список (каждый с новой строки). Импорт из .txt
2. **Аккаунты** — добавьте аккаунты OLX.BA (email/логин + пароль). Выберите аккаунт для отправки
3. **Текст сообщения** — шаблон по умолчанию на боснийском
4. **Ссылки** — вставьте ссылки на объявления или импортируйте из .txt
5. **Настройки** — задержка мин/макс, количество параллельных задач (2–3)
6. Нажмите **«Запустить отправку»** — приложение войдёт в аккаунт и начнёт отправку

## Требования

- Windows 10/11
- Python 3.10+
- Аккаунт на OLX.BA

## Примечания

- Используйте разумные задержки (3–7 сек), чтобы избежать блокировки
- Не ставьте слишком много параллельных задач (рекомендуется 2–3)
- При первом запуске браузер откроется для входа в OLX — войдите вручную
